What Phase 1 does

  • A personalized text goes out Monday at 8:00 AM. The send time is configurable.
  • The employee taps their own link straight into their assigned talk — no PIN, no login.
  • The talk can be shown as the original document, as a Guided Talk, or both.
  • They acknowledge and submit individually, and see a confirmation.
  • If it is still incomplete, a reminder goes at 48 hours and then every 24 hours.
  • Monday 7:00 AM, an admin digest lists everything still unsigned.
  • The office sees completion, timings and active engagement time per person.

Production security design

Not built in this demo — this is the design the live build must follow.

  • Each link carries a random signed or hashed assignment token, tied to exactly one employee and one Toolbox Talk assignment.
  • Tokens expire. An expired token opens nothing.
  • A token must never contain or reveal a phone number or an employee ID, and must not be guessable from another token.
  • There is no generic public submission URL. Without a valid token there is nothing to submit to.
  • Tokens in this demo are fictional, generated locally, and reach nothing.

Future expansion — not in Phase 1

A reusable PIN portal can be added later to give employees a standing way in — training records, previous talks, inspections and other workflows. Phase 1 deliberately stops at the single-purpose secure link, because it needs no account, no password reset and no support burden. The PIN portal is not built and is not included in Phase 1 pricing.
